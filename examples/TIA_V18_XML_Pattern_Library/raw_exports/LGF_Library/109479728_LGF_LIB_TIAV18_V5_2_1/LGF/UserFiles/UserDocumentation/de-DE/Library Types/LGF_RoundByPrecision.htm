Funktionsbeschreibung

Diese Funktion rundet eine Gleitkommazahl (LReal) auf eine bestimmte Anzahl von Dezimalstellen.
Er skaliert den Wert, kürzt ihn auf eine ganze Zahl und skaliert ihn dann erneut, um das gerundete Ergebnis zu erhalten.
